# ⚡ WEATHER RUSH

A fast-paced 2-player weather guessing party game for English class.

**▶ Play online:** https://notcronox.github.io/weather-rush/

One player is the **Weather Master** (sees a secret weather), the other is the **Weather Detective** (guesses it from English clues). Pass the device between turns.

- 5 rounds: Easy Weather, Emoji Weather, Weather Scenario, Mystery Weather and Weather Rush (15 seconds!)
- Score, streak bonus, speed bonus, countdown timer
- Classic and Versus modes
- Vocabulary: sunny, rainy, cloudy, windy, stormy, snowy, foggy, hot, cold

Runs entirely in the browser — a single `index.html` file, no installation.
